# Inventory ERP - Mini ERP System
Author: Rudrani Rachita Das | B.Tech CSE | Gandhi Engineering College
Tech: Laravel, React.js, MySQL, PHP, Git

Features:
- Product CRUD with REST API /api/products
- Dashboard with total stock value & low-stock alert
- MySQL 2 tables: users, products
- React + Bootstrap frontend

How to Run:
Backend: cd backend -> composer install -> php artisan migrate -> php artisan serve
Frontend: cd frontend -> npm install -> npm start
